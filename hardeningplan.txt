Phase 1B decision log (recorded before implementation, 2026-08-03):
  * New API tokens expire after 90 days by default and may not exceed 365 days;
    both values are operator-configurable, validated positive integers and the
    default may never exceed the maximum.
  * Existing non-expiring tokens remain usable for a controlled compatibility
    window, but are labelled legacy/no-expiry in both user and administrator UI
    so operators can rotate them. Phase 1B does not silently break deployed
    SolidWorks integrations.
  * Ordinary self-service password changes revoke every API token, as do admin
    password resets, CLI password resets, permission-test credential refreshes
    and account deactivation. Reactivation never restores revoked tokens.
  * Rotation is user-controlled, returns the replacement secret once, and
    guarantees that a concurrent loser token is revoked. Administrators may
    explicitly revoke one user's token or all active API tokens, but may not
    mint or retrieve another user's secret.
  * Phase 1B closed the API-token portion of IAM-REV-01; Phase 1C subsequently
    closed its browser-session portion.
