# Security documentation for maintainers

These developer policies are not published in end-user Help.

- [`../../SECURITY.md`](../../SECURITY.md) describes the supported security
  model and private reporting channel.
- [`supply_chain_policy.md`](supply_chain_policy.md) defines dependency, image,
  CI and release-pin controls.
- [`risk_acceptance_template.md`](risk_acceptance_template.md) defines the
  minimum record for a time-limited security exception.
- [`role_intent_feature_matrix.md`](role_intent_feature_matrix.md) records the
  intended standard-role boundaries.

Current scan evidence belongs in CI artifacts and release records. Do not turn
point-in-time finding counts or remediation transcripts into permanent policy
documents.
